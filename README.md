# 本地图片加水印（local-image-watermark）

一款纯前端、离线运行的图片批量水印工具。所有处理都在本机浏览器或桌面应用内完成，图片不会上传到任何服务器。

提供两种形态：

- **网页版**：单个 `index.html`，双击即可使用
- **桌面版**：Electron 封装，提供 Windows 便携版与安装包

---

## 功能特性

### 图片导入

- 支持 JPG / PNG / WebP / GIF / BMP / TIFF / SVG / ICO / AVIF / HEIC
- 支持拖拽、点击选择、剪贴板粘贴，可一次导入多张
- HEIC 通过 libheif 在本地解码（4096×3072 约 1.4s），RAW 相机原图暂不支持
- 批量导入显示「正在导入 i/N」进度提示

### 文字水印

- 动态变量：`{date}` 日期、`{time}` 时间、`{name}` 文件名、`{seq}` 序号、`{rand}` 随机编号（每张图独立）
- 字号按图片边长百分比设置，可调颜色与不透明度
- 支持文字阴影、描边、底色框
- 内置系统字体，支持上传 ttf / otf / woff 自定义字体

### 图片 / Logo 水印

- 上传任意透明 PNG / JPG 作为 Logo
- 尺寸按比例调节，旋转角度可调，其余位置参数与文字水印共用

### 位置与排布

- 九宫格快速定位（左上、上中、右上 … 右下）
- 平铺整张：可单独调节边距、间距与角度
- 在预览图上直接拖动水印；平铺模式下拖动为整体平移
- 「重置位置」一键恢复平铺排布并清零偏移

### 预览与查看

- Canvas 实时预览，大图按容器等比缩放，高清屏自动适配 DPR
- 「对比原图」一键查看无水印效果，便于核对遮盖程度
- 预览基底离屏缓存，拖动与调节时只重绘水印层

### 预设

- 保存 / 应用 / 删除自定义预设，基于 localStorage 持久化
- 首次使用自动注入「证件水印」「版权水印」两个内置模板

### 导出

- 单张下载，或一键 ZIP 批量导出
- 格式：自动 / JPEG / PNG / WebP / AVIF / BMP / GIF / TIFF / ICO / SVG
- 统一画质滑杆，文件名支持前缀 / 后缀 / 序号
- 批量导出自动去重（`pic-wm.png`、`pic-wm-1.png`…），ZIP 内不会互相覆盖
- 导出格式旁提供动态说明：BMP / TIFF 预估体积、GIF 256 色、ICO 256px 限制、SVG 为内嵌位图

### 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Delete` | 删除当前选中的图片 |
| `Ctrl / Cmd + Enter` | 导出全部图片 |

## 快速开始

### 网页版

1. 下载或克隆本仓库
2. 用 Chrome / Edge 打开 `index.html`

无需安装、无需本地服务器、无需联网。建议 Chrome / Edge 100 及以上；浏览器是否支持 AVIF 编码取决于版本，不支持时该选项会标记为「仅可导入」并禁用。

### 桌面版（Electron）

环境要求：Node.js 18+

```bash
cd electron
npm install
npm start        # 本地调试运行
npm run dist     # 打包 portable + nsis，输出到 electron/dist
```

打包产物：

- `本地图片加水印-便携版-1.0.0.exe`：双击即用，无需安装
- `本地图片加水印-安装包-1.0.0.exe`：安装向导，可选安装目录并创建快捷方式

> 未做代码签名，首次运行若触发 Windows SmartScreen，请选择「更多信息 → 仍要运行」。

## 使用步骤

1. **导入图片**：拖拽到窗口、点击选择，或直接粘贴剪贴板图片
2. **选择水印类型**：文字水印或图片 / Logo
3. **调整样式**：输入文案（可用动态变量）、设置字体、字号、颜色、不透明度，按需开启阴影 / 描边 / 底色框
4. **确定位置**：九宫格选点、平铺整张，或直接在预览图上拖动
5. **导出**：单张「下载这张」，或设置文件名与格式后「导出全部（ZIP）」
6. **复用配置**：将当前参数保存为预设，下次一键套用

## 导出格式说明

| 格式 | 特点 | 适用场景 |
| --- | --- | --- |
| 自动 | 跟随源文件格式，无法编码时回退 PNG | 日常批量处理 |
| JPEG | 有损压缩，画质滑杆生效，透明区域填白 | 照片分享 |
| PNG | 无损压缩，保留透明 | 需要透明背景 |
| WebP | 有损压缩，体积通常小于 JPEG | 网页配图 |
| AVIF | 新一代格式，体积小，编码较慢 | 浏览器支持时优先 |
| BMP | 无压缩位图，体积很大 | 特定兼容需求 |
| GIF | 最多 256 色，渐变可能出现色带 | 线条 / 纯色图形 |
| TIFF | 无压缩位图，体积很大 | 印刷 / 归档 |
| ICO | 最长边限制 256px，大图等比缩小 | 图标素材 |
| SVG | 容器格式，内嵌 PNG 位图，并非真正矢量 | 需要 SVG 后缀的场景 |

## 项目结构

```
local-image-watermark/
├── index.html                 # 网页版（单文件应用，含全部 UI 与逻辑）
├── lib/
│   ├── utif.min.js            # TIFF 解码
│   ├── gifenc.js              # GIF 编码
│   └── libheif-bundle.js      # HEIC 解码
├── electron/
│   ├── main.js                # Electron 主进程
│   ├── package.json           # 依赖与打包配置
│   ├── build/                 # 应用图标（png / ico）
│   └── scripts/
│       ├── sync-app.js        # 打包前同步 index.html 与 lib
│       ├── afterPack.js       # 写入 exe 图标与版本信息
│       ├── make_icon.py       # 生成应用图标
│       └── bin/rcedit.exe     # 修改 exe 资源
├── 测试报告.html              # 自动化测试与产物校验报告
└── README.md
```

说明：`electron/app` 由 `scripts/sync-app.js` 在打包前自动生成，`electron/dist`、`electron/.cache`、`electron/node_modules` 均为构建产物或依赖，不纳入版本管理。

## 技术实现

- 原生 JavaScript + Canvas 2D，无前端框架、无构建步骤，网页版即开即用
- UTIF.js 解码 TIFF，gifenc 编码 GIF，libheif-js 解码 HEIC，全部本地运行
- 桌面版基于 Electron，开启 `contextIsolation` 与 `sandbox`，未启用 Node 集成
- 桌面版导出下载走系统「另存为」对话框，便于连续导出时指定位置
- 单实例锁、外链交给系统浏览器、禁止页面跳转

## 隐私说明

所有图片仅在本机内存与 Canvas 中处理，不发起任何网络请求；预设与界面设置保存在浏览器 / 应用的本地存储中。

## 已知限制

- RAW 相机原图（CR2 / NEF / ARW 等）不支持
- 部分浏览器仅支持 AVIF 解码，导出选项会禁用并标注「仅可导入」
- BMP / TIFF 为未压缩格式，体积可能达到源 JPEG 的 20 倍以上
- GIF 最多 256 色，渐变区域可能出现色带
- ICO 最长边限制 256px，超出会等比缩小
- 桌面版未签名，可能出现 SmartScreen 提示
